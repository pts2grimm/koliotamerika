Transformation: retain place name, region, municipality and postal codes; group rows only by identical place/region/municipality/admin identifiers, combine codes. 5304 source rows -> 5301 entries. Preserve homonymous places and ambiguous codes. Coordinates and other identifiers are not shipped.

This is a settlement-level directory, NOT a complete street/district directory. Codes ending in 00 and ambiguous entries require explicit confirmation. Other suggested codes remain editable and must be checked against the buyer's address. Sofia's 1000 is never silently applied. CRC confirms district-level codes exist: https://crc.bg/files/_bg/1000_Sofia_grad.pdf . We do not fabricate district-code ranges.

Data is bundled in a lazy admin-only chunk. No buyer/address data is sent to GeoNames. To update, repeat the documented download/transformation and review cardinality, ambiguous places, and license before committing.
